# 中医药知识图谱 · 症状反查检索

一个几十行的 Streamlit 界面，把 `data/` 里的三张源表变成可交互的检索：
输入症状 → 找到可能对应的证型 → 看治法与主治方剂 → 展开方剂组成药材（性味、归经、功效、禁忌）。

## 运行

```bash
pip install streamlit pandas
streamlit run app.py
```

浏览器自动打开后，左侧选模式。

## 两种用法

**辨证检索**：在输入框里填症状关键词，用空格分隔，例如

```
恶寒 无汗 脉浮紧
```

程序按「命中症状数」排序返回候选证型，点开任一证型即显示治法、主治方剂和完整组成。

**药材速查**：选一味药，看它的性味、归经、功效、禁忌，以及出现在哪些方剂里。

## 数据从哪来

三张表都是人工整理的，不是爬的：

| 文件 | 内容 | 规模 |
| --- | --- | --- |
| `data/herbs.csv` | 药材：性味、归经、功效、分类、禁忌 | 74 味 |
| `data/formulas.csv` | 方剂：组成（引用药材名）、主治证型 | 20 首 |
| `data/syndromes.csv` | 证型：症状、治法、对应方剂 | 20 个 |

`src/build_graph.py` 把它们展开成 396 个节点、819 条边；`src/validate.py` 做引用完整性与逻辑自洽校验。

构建产物不入库，需要时自己生成（可直接导入 Neo4j 一类的图数据库）：

```bash
python src/build_graph.py --out data/graph
# → data/graph_nodes.csv（396 行）、data/graph_relations.csv（819 行）
```
