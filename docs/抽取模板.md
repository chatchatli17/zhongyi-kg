# 抽取模板：从药典/教材条目到三张表

这份模板规定「一条原文」被拆成哪些字段、每个字段写什么格式。目的是让两个人分别抽取同一批条目时，
产出可以直接合并、可以用 `src/validate.py` 校验，而不是两份格式各异的手工表。

## 一、从一条药材原文开始

药典条目一般长这样（节选，示意）：

> **麻黄**　辛、微苦，温。归肺、膀胱经。发汗散寒，宣肺平喘，利水消肿。
> 用于风寒感冒，胸闷喘咳，风水浮肿。表虚自汗、阴虚盗汗及虚喘者慎用。

抽取后应得到一行 `data/herbs.csv`：

```csv
麻黄,辛、微苦，温,肺;膀胱,发汗散寒;宣肺平喘;利水消肿,解表药,表虚自汗者慎用;阴虚盗汗者慎用
```

### 字段规则

| 字段 | 来源 | 规则 |
| --- | --- | --- |
| `name` | 条目标题 | 用药典正名，不加"（炙）"等炮制后缀；炮制品另立一行并在 `note` 标注 |
| `nature` | "性味"句 | **整体保留原文**，逗号、顿号不改写；只去掉句末句号 |
| `meridians` | "归…经"句 | 按 `;` 分隔，去掉"归""经"二字，只留脏腑名（`肺;膀胱`） |
| `effects` | "功效"句 | 按 `;` 分隔，**保持原文语序**，不改写成现代白话 |
| `category` | 章标题 | 取值必须是 `解表药 / 清热药 / 泻下药 / 祛风湿药 / 化湿药 / 利水渗湿药 / 温里药 / 理气药 / 消食药 / 驱虫药 / 止血药 / 活血化瘀药 / 化痰止咳平喘药 / 安神药 / 平肝息风药 / 补虚药 / 收涩药 / 涌吐药 / 攻毒杀虫止痒药 / 拔毒化腐生肌药` 之一 |
| `caution` | "注意/禁忌"句 | 按 `;` 分隔，保留"慎用/禁用/不宜与…同用"原表述，**不得自行推断** |

**分隔符约定**：字段之间是英文逗号 `,`；同一字段内的多值用英文分号 `;`；
**字段内部一律只用中文标点**（，、；），因为英文逗号与分号已被用作分隔符。含逗号的原句要么整段保留，要么拆成两值。

## 二、从一条方剂原文开始

> **麻黄汤**　麻黄（去节）三两，桂枝二两，杏仁（去皮尖）七十个，甘草（炙）一两。
> 主治外感风寒表实证。

抽成 `data/formulas.csv`：

```csv
F01,麻黄汤,麻黄;桂枝;苦杏仁;甘草,S01,辛温解表基础方
```

| 字段 | 规则 |
| --- | --- |
| `fid` | `F` + 两位序号，按方剂在教材中出现的顺序编号，**不复用** |
| `composition` | 只取**药材名**，去掉剂量、炮制说明、煎服法；药材名必须与 `herbs.csv` 的 `name` **逐字一致**（`杏仁`→`苦杏仁`，`生地`→`生地黄`） |
| `syndrome_id` | 必须指向 `syndromes.csv` 已存在的 `sid`；找不到就先建证型行，不许留空 |
| `note` | 可选，一句话说明该方的定位（"补气基础方"），不写疗效宣传语 |

## 三、从一条证型开始

> 外感风寒表实证：恶寒重、发热轻、无汗、头身疼痛、鼻塞流清涕、脉浮紧。治宜辛温解表、宣肺散寒。

```csv
S01,风寒表实证,恶寒重;发热轻;无汗;头身疼痛;鼻塞流清涕;脉浮紧,辛温解表;宣肺散寒,F01
```

| 字段 | 规则 |
| --- | --- |
| `sid` | `S` + 两位序号 |
| `symptoms` | 每条症状用 `;` 分隔，**保留程度词**（"恶寒重"不能写成"恶寒"），至少 3 条 |
| `principle` | 治法，按 `;` 分隔，与教材"治法"句一致 |
| `formula_id` | 与方剂表**双向一致**：方剂的 `syndrome_id` 指回来必须是本行 `sid` |

## 四、抽完必须跑的两条命令

```bash
python src/validate.py     # 必填、唯一性、引用完整性、逻辑自洽；有错退出码 1
python src/build_graph.py  # 打印实体/关系统计并检查悬挂边
```

## 五、常见返工点

1. **药材名对不上**：方剂里写"杏仁"，药材表里是"苦杏仁"，校验会报"含未收录药材"。
2. **证型与方剂互指错位**：复制上一行时忘了改 `sid`。
3. **用英文逗号写性味**：`辛,甘,温` 会被 CSV 解析成三列，整行报废。
4. **擅自合并功效**：把"发汗散寒"和"宣肺平喘"合成"发汗平喘"，原文没了，后续无法回查。
5. **漏记禁忌**：药典的"注意"项最容易被跳过，但它恰恰是图谱里价值最高的边（安全性检索靠它）。

## 六、批量抽取的现实做法

本项目的 74 味药材是**手工录入**的。如果要扩到药典全量（约 600 味），建议：
用 `pdfplumber` 把药典 PDF 按条目切块 → 用正则抓「性味」「归经」「功效」「注意」四个句段 → 人工过一遍
（自动抽取在这四类字段上的准确率通常只有 70–85%，归经与性味尤其容易串行）。**人工核对环节不能省**，
否则图谱里的错边会一路传导到检索结果。
